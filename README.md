# Cold Email Generation Tool

An AI-powered Cold Email Generator built using Python, LangChain, and Groq.

## Features

* Generate professional cold emails
* Customize by job role and company
* Powered by Groq LLMs
* Secure API key management using `.env`

## Installation

```bash
pip install -r requirements.txt
```

## Environment Variables

Create a `.env` file:

```env
GROQ_API_KEY=your_api_key
```

## Run

```bash
python models/model.py
```

## Example

Input:

* Job Role: Software Engineer Intern
* Company: Google

Output:

* Professional cold email tailored to the role and company.

## Tech Stack

* Python
* LangChain
* Groq API
* dotenv
* Git/GitHub
